# PHP Assignment 1 – Tattoo Studio Gallery

## Project Overview

Tattoo Studio Gallery is a PHP and MySQL web application developed for Assignment 1 in the PHP and MySQL Development course.

The application uses a MySQL database containing fictitious tattoo studio data. PHP is used to connect to the database, retrieve the stored information, and dynamically display the data in the browser.

The project follows the concepts and application structure demonstrated in the Contact Manager class project.

## Features

- PHP and MySQL database integration
- Database connection using PHP
- Database error handling
- Retrieval of data from MySQL
- Dynamic display of database records
- Reusable header and footer components
- Custom CSS styling
- Local development using XAMPP
